## Source-to-Sink Evidence Modeling
Every finding generated by Layer 1 contains structured provenance:
- **Sink**: The exact AST node and line where the vulnerable operation is invoked (e.g. `cursor.execute(sql)`, `subprocess.call(cmd, shell=True)`).
- **Source-to-Sink Evidence**: Trace from the variable assignment, string interpolation, or parameter input down into the target sink.
- **Remediation**: Actionable guidance for replacing vulnerable patterns with parameterized or safe alternatives.
